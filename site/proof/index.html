Getting there honestly.

Getting a clean result that means something took some work on Dead Heat itself.

Kane CLI sometimes re-saved a user’s change after the race, which repaired the lost update before it could be checked, so Dead Heat now treats any save after the release as “cannot be judged”.

Kane CLI also sometimes missed the small red refusal text that the screenshots show, so a 409 answer now counts as a refusal unless the page told the user the save had worked.

Users reported this Kanboard behaviour in kanboard#2741 and kanboard#944; both issues were closed without a fix, and the current release still behaves the same way. The setup script and race file are in examples/kanboard, so the result can be reproduced.
