Try it in two minutes.

You need Node 22 or newer, Google Chrome, and Kane CLI logged in. Dead Heat itself has no dependencies.

Node 22 or newerGoogle ChromeKane CLI, logged in

Kane CLI

TestMu AI’s browser agent. Dead Heat uses it to drive both users and to check each one after the reload.

npm install -g @testmuai/kane-cli
kane-cli login

Dead Heat

Straight from GitHub.

npm install -g github:SudeepGowda55/deadheat

The desk example

examples/desk is a tiny booking page with one hot desk and a classic mistake: it checks that the desk is free, waits a moment, then books it. The run takes about six minutes and 150 Kane CLI credits.

git clone https://github.com/SudeepGowda55/deadheat && cd deadheat/examples/desk
deadheat race

The Kanboard race

The setup script fetches Kanboard 1.2.58, starts it once, and seeds two users, one project and one task through its own API. It needs git, PHP 8.1 or newer (brew install php), sqlite3 and curl. The real run took 266 credits and about 12 minutes.

cd deadheat/examples/kanboard && ./setup.sh
deadheat race

Your own app

Write a race file, describe your two users in plain English, and race every order. Each run writes .deadheat/report.html, a single file with the screenshots inside it, so it can be attached to a pull request as it is.

deadheat init
deadheat race

With your coding agent

Dead Heat races every order, writes a brief when a user silently lost, runs your agent’s command with it, restarts the app and races again, until every order is clean or --max attempts. {brief} becomes the brief’s path.

deadheat fix --with "your-agent {brief}"
deadheat race --agent

With --agent, standard output is one JSON object per line and the last line carries every verdict. The skill file skills/deadheat/SKILL.md teaches a coding agent when a handler needs a race, how to write one, and how to read the result.

Command or flagWhat it does
deadheat race [name]Race every order (or --orders together) and report who silently lost.

deadheat initWrite an example deadheat.json.

--max <n>Fix attempts, default 3.

Exit code: 0 clean, 1 a user silently lost, a save crashed the app, or an invariant broke, 2 the race could not be run.
